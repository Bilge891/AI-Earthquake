# TURKIYE EARTHQUAKE PREDICTION MODEL

This project uses artificial intelligence and human analysis to predict potential earthquakes in regions within the borders of Türkiye.

# FEATURES

This application provides an estimated earthquake magnitude based on coordinates, focal depth, and seismic memory (magnitude of the previous earthquake in the same localized grid).

# ATTENTION

Although this application has been vetted and uses official data, it carries a high margin of error and is not an official project.
